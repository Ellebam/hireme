## Architect Plan

**Rationale:** Codebase is in an unusually favorable position for this major upgrade:
- All client-side (`'use client'` everywhere) — zero RSC migration
- No `params`/`searchParams`/`cookies()`/`headers()` usage — async migration doesn't apply
- No `next/image` — no Image component API changes
- No middleware — no middleware migration
- `next-intl` 3.26.5 explicitly supports Next 15 + React 19
- Already on `next/navigation` — no router migration
- `@testing-library/react` 16.3.2 already React 19 compatible
